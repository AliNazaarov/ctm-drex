# Handoff

Where CTM × Drex stands, so the next session can continue without the chat.

## What it is

CTM is the agent team an immigration attorney runs for O-1A petitions. This repository is the checking layer: Drex
checks every claim in a petition draft against the exhibits, inside the Intern harness, and writes a receipt the
attorney signs off. Built for Nace AI's Drexathon (Apex Predator track: Drex vs the giants).

## How it runs

- Harness: Intern, headless. System 2 = Qwen3.8-27B on DeepInfra (drafts). System 1 = Drex (`drex-latest`,
  drex-max-v1.1) for Intern's own decisions. CTM's extension `ctm_drex.intern_ext:CtmReceipts` checks the draft with
  Drex when the agent finishes, keeps every round in `ctm-receipt.md`, and reopens the run once if a claim is not
  backed (claims already marked `[client to provide evidence]` do not reopen it).
- NDI parses PDF exhibits (`ctm_drex/ndi.py`, cached as `<name>.ndi.md`).
- Keys: `~/.intern/.env` (NACE_API_KEY, DEEPINFRA_API_KEY, OPENROUTER_API_KEY, FIREWORKS_API_KEY). Never commit.

## Results

`docs/results.md` (generated by `python -m bench.report`), method in `docs/evals.md`, deck in `deck/` (`python
deck/fill.py --pdf`). The demo take is `demo/run3` (not committed; `demo/run*/` is ignored).

## Open items

- Extractor recall is not measured; claims in headings and drafting notes are sometimes picked up.
- The synthetic petition set is too easy to rank models (most score ~1.00); a harder set is the next eval.
- LLM-AggreFact data is not committed (CC BY-ND); `bench/aggrefact.py sample` rebuilds the sample from a parquet.
- The number rule ignores legal citations; dates written in words are not compared.
